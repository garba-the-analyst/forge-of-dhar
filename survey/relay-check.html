Relay check

For the person who runs the survey. This page tests the real route a respondent's browser takes to the relay (relay/Code.gs), from this web address. It is not part of the survey and is not linked from it.

1. Settings in assets/config.js

2. Is the relay alive?

Opens the relay web address and reads its reply. This checks the deployment (the URL, and "Who has access: Anyone") and that this page is allowed to read the answer.


      


      

        
3. Send a test response

        
Sends one test message with a tiny PDF through the relay, exactly as the survey does. A message whose subject starts with "[TEST]" should reach the inbox of the account that owns the script within a minute, and a row marked "test-emailed" should appear in the "Shaping Dhar responses" sheet.
